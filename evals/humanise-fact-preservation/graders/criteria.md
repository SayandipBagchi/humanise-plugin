# Criteria: humanise-fact-preservation

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Invents no metric, percentage, study, quote, user feedback, or causal mechanism
- [ ] Either narrowly preserves the unsupported outcome claim or explicitly flags that it needs evidence
- [ ] Removes inflated significance and generic success language
- [ ] Does not hide the evidence gap behind a stack of added hedges
- [ ] Adds no confident conclusion and no generic explanation of what was done
- [ ] Contains no dash and no not-X-but-Y construction
