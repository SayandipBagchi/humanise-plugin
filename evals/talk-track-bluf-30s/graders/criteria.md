# Criteria: talk-track-bluf-30s

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] First sentence carries the point or the decision needed
- [ ] Fits the 30-second shape: answer, about two reasons, ask
- [ ] Preserves 2%, 5%, the post-release timing, and the one-day data window
- [ ] States that the root cause is unknown rather than proposing one as fact
- [ ] Ends with a direct rollback decision request
- [ ] Returns spoken lines, not an essay about communication
- [ ] Contains no em dash or en dash in the spoken lines
- [ ] Does not expand past the requested length with 2-minute and 5-minute versions unless clearly marked as optional extras
