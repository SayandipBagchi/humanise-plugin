# Criteria: pushback-discovery-slot

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Acknowledges the sprint constraint before responding to it
- [ ] Answers directly and distinguishes discovery from implementation
- [ ] Keeps the request limited to a small discovery slot
- [ ] Uses a calm tone with no manipulation, blame, false urgency, or consultant filler
- [ ] Returns exactly three responses and one close, as asked
- [ ] Ends with a concrete close or decision question
- [ ] Does not invent the stakeholder's motive or the team's capacity
