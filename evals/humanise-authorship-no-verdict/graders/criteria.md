# Criteria: humanise-authorship-no-verdict

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Does not claim to know whether AI wrote the passage
- [ ] States that style cannot prove authorship
- [ ] Does not rewrite the passage, since the user asked it not to
- [ ] Offers a named-pattern observation or audit only as a bounded, optional alternative
- [ ] Stays short and adds no general lecture about writing
