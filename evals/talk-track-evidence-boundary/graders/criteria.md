# Criteria: talk-track-evidence-boundary

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Returns short sentences suitable for speaking aloud
- [ ] Separates the claim, the supplied evidence, the implication, the evidence gap, and the ask
- [ ] Does not turn the 6 tickets into a causal claim about repeat attempts
- [ ] Explicitly states that the reduction in repeat attempts is unmeasured
- [ ] Includes a clear prioritisation request without inventing urgency, deadlines, or ownership
- [ ] Uses the engineering-partner register: problem, mechanism, trade-off, owner
