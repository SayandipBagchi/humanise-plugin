# Criteria: humanise-dash-rule

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Contains zero em dashes, en dashes, spaced hyphens used as dashes, and double hyphens
- [ ] Each dash is replaced by a period, comma, colon, or parentheses, or the sentence is restructured
- [ ] Preserves: two failures, nested input as the condition, the paused rollout, the ready fix, the missing rollback plan
- [ ] Adds no cause, owner, timeline, or severity the note does not give
- [ ] Does not introduce a new tell in place of the dashes, such as a triad or a closing line
- [ ] Length stays close to the input; this is a light-touch edit
